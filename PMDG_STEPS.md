# PMDG 737 and Simbrief Integration

(Youtube Link)[https://www.youtube.com/watch?v=N30ckxx6xeY&t=13s]

1. Flight Plan Verification (0:27 - 0:40): Use the universal flight tablet to confirm the flight plan details from SimBrief.
2. FMC Position Initialization (1:02 - 1:12): Navigate to the FMC and enter the reference airport code.
3. Flight Plan Import (1:12 - 1:24): Perform a 'Flight Plan Request' to pull the route directly from the SimBrief account.
4. Fuel and Payload Import (1:42 - 2:20): Select 'Set Fuel' and 'Set Payload' to automatically import block fuel and zero fuel weight data.
5. Route Loading (2:25 - 3:04): Request the flight plan, wait for it to populate, and load it into the FMC, confirming the route against the operational flight plan.
6. Performance Initialization (3:07 - 3:57): Request the performance data, load it, and adjust the flight level as needed to ensure accuracy.
7. Takeoff Setup (4:09 - 4:40): Enter N1 limits, configure takeoff flaps, and set the center of gravity (CG).
8. IRS Alignment (4:41 - 4:56): Switch the overhead panel settings to 'NAV' and align the IRS systems.
9. Departure Selection (4:58 - 5:10): Select the departure runway and SID from the FMC.
10. Final Speed Setup (5:13 - 5:19): Complete the initialization by setting the V-speeds.
